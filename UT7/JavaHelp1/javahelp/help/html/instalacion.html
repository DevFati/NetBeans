Instalación

Para instalar el juego 3 en Raya en NetBeans, sigue estos pasos:

  1. Descarga el proyecto desde el repositorio en GitHub.
  2. Abre NetBeans y selecciona Archivo → Abrir Proyecto.
  3. Navega hasta la carpeta donde descargaste el juego y ábrelo.
  4. Compila y ejecuta el proyecto para asegurarte de que funciona correctamente.
