Instalacion

Sigue estos pasos para instalar el Gestor de Tareas:

  1. Accede al GitHub de DevFati.
  2. Dentro del repositorio Netbeans, navega hasta Unidad4 → gestordetareas.
  3. Descarga el proyecto y abrelo en NetBeans.
  4. Compila y ejecuta el proyecto para verificar su correcto funcionamiento.
