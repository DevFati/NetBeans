Solucion de Problemas

Si experimentas algun problema con la aplicacion, prueba las siguientes soluciones:

  • El programa no inicia: Verifica que Java y NetBeans esten correctamente instalados.
  • No se guardan las tareas: Asegurate de tener permisos de escritura en la carpeta del proyecto.
  • La interfaz no responde: Reinicia la aplicacion o cierra otros programas que puedan afectar su rendimiento.
